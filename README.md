# OG Orbit

A remote-friendly launcher for Android TV, made by OGSmuggy.

## Download

Get the latest APK from [Releases](https://github.com/OGSmuggy/OG-Orbit/releases). Install it on your TV and select OG Orbit as your Home app in Android settings. Keep the same installation when updating so your layout is preserved.

The base preview menu has three tiles: Store, About and Backup. The top-right shortcuts open Wi-Fi, device settings and the preview menu.

## Updates

OG Orbit checks this repository's latest published release when it starts. You can install straight away or download now and install after a device restart. Android still asks you to confirm installation. For the deferred option, the installer is offered when OG Orbit opens after the restart; it does not install while the device is switched off.

Use About > Updates to check manually or change the remembered option. The first update needs Android's "Allow from this source" permission. Updates use the same package and signing key, so your Home choice should stay in place. A Home picker is offered if Android clears that choice.

## Store

The Store pages are in place, but there are no downloadable modules yet. Themes, icon packs, wallpapers, screensavers and other optional modules will be listed here as they become available.

## Compatibility

Tested on Chromecast with Google TV HD, Android 14. Other Android TV devices are not tested yet. Some devices restrict changing the Home app or sideloading updates.

## Repository contents

This repository holds release APKs, update metadata and Store content. The launcher source code is private.

Found a problem? Open an issue with your TV model, Android version and what happened. Don't include passwords, tokens or private files.
