# Wallpaper

Requires OG Orbit 0.2.0 or newer.

Open Store > Wallpaper > Install, then open the Wallpaper tile in the preview menu.

Choose Collection, Live Wallpapers, Gradients or Your image. Select a wallpaper to preview it, then choose Apply. Back discards an unapplied preview.

In Live Wallpapers, select a MotionBgs thumbnail to stream a preview. Download saves the loop to your collection; Apply sets it as your wallpaper.

Delete removes a personal collection copy. Your original file and applied wallpaper stay in place.
