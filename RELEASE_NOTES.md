First public build of OG Orbit.

The base launcher has a favourites dock, an app grid and a live preview menu with Store, About and Backup.

This release adds GitHub update checks when the launcher starts. Choose to install straight away or download now and install after your next device restart. Tick "Remember my option" to save your choice. You can change it under About > Updates.

Android asks for permission before installing an update. Updating keeps your apps, layout and existing Home selection. If a device clears its Home selection, OG Orbit opens the normal Home picker when it next runs.

The Store is empty for now. Optional modules, themes and icon packs are coming later.

Tested on Chromecast with Google TV HD running Android 14. Other Android TV devices have not been tested yet.
